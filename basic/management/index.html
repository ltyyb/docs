管理公约

厦门六中（同安校区）音游部的管理目标、行为规范与处罚措施。

V3.0.0 | by 厦门六中(同安校区) 音游部 管理组

发布时间(GMT +08:00): 2026/3/21 20:02

一、目的与加入条件

1.1 厦门六中(同安校区)音游部旨在为厦门六中(同安校区)的音游玩家们，以及任何对我校/我社群感兴趣的其它地区学生提供一个交流、和谐互助的社群平台。任何厦门六中(同安校区)的学生、往届毕业生、以及现就读于其它学校的学生均可以申请加入本社群。

1.2 加入本社群的成员必须遵守本公约的规定。

二、管理目标与原则

2.1 本公约旨在更好地管理厦门第六中学(同安校区)音游部，维护和谐稳定的交流环境。

2.2 本社群的管理人员应秉持公正、客观、公开的原则执行管理职责。

2.3 本社群部分群员管理操作可能由机器人完成，包括但不限于: 主群审核放行、人员管理与统计、问卷收集与推送。但我们将确保机器人相关操作符合包括此规范在内的任何约束，关键实现均由我们自行编写，相关项目 (包括本文档页面) 已开放源代码，详见我们的 GitHub Organization Repositories

三、禁止行为

3.1 本社群严格禁止存在" 音游王 " 以及任何类似造假行为。我们将在问卷审核阶段将是否存在造假嫌疑/行为作为主要评判要点。

" 音游王 "为贬义词，通常是指水平较低的音游玩家，或根本没接触过音游的门外汉，出于炫耀、自卑或搞事等原因，盗用别人的成绩图、手元，或伪造虚假的游玩结果（包括但不限于PS成绩图、使用AUTO（谱面自动播放）或谱面预览视频并故意当作自己亲自打出来的成绩等），从而显示或炫耀自己或自己的亲友玩音游的“高水平”，并借此嘲讽其他普通玩家。

3.2 在本社群内的交流中，请保持和谐、包容的语气，不得歧视、排挤某类正常音游或正常音游玩家群体。

3.3 加入本社群后，不得在任何相关群中发表小鬼、钓鱼、跳脸、恶俗等言论。

3.4 加入本社群后，不得在任何相关群中发表与音游无关的色情、敏感等违法违规信息。

3.5 加入本社群后，不得在任何相关群中发表任何政治、宗教、NSFW 等平台禁止的敏感话题。

四、处罚措施

4.1 如有违反本公约的行为，管理组有权根据情况对违规成员给予处罚，包括但不限于警告、禁言、暂时移除、终身禁审等。

4.2 管理员在执行处罚操作时必须客观、公正，并保留相关证据。

4.3 如对管理员的管理有异议，可以私信部长 Aunt_nuozhen 协助解决。

五、生效与修改

5.1 本公约自发布之日起生效，适用于厦门六中(同安校区)音游部的所有成员。

5.2 如有必要对本公约进行大量破坏性更改时，应征集不少于 8 名正式成员的意见，并公布于群中适当位置。

5.3 本公约的修改可能不会及时通知到所有成员，成员应定期查看本公约的最新版本。

六、附则

6.1 本公约的解释权归厦门六中(同安校区)音游部管理组所有。

6.2 本公约的补充规定将根据实际情况进行制定，并在适当的时候向本社群成员公布。

6.3 本公约的任何修改或补充都应符合厦门六中(同安校区)音游部的相关规定和法律法规。
